================================================================================
                        HOW IT WORKS
================================================================================

USER INTERACTION FLOW:

1. User opens your live URL
   https://yourapp-*.vercel.app
           ↓
2. Browser loads React app (from CDN)
           ↓
3. User types message and hits Enter
           ↓
4. Message sent to: /api/chat (serverless function)
           ↓
5. Backend creates ToolLoopAgent with:
   • OpenAI model
   • 6 real tools
   • Streaming enabled
           ↓
6. Agent processes request (may call tools):
   • Web Search Tool
   • Content Fetch Tool
   • Calculator Tool
   • System Info Tool
   • Canvas Tool
   • Session Tool
           ↓
7. Response streams back in real-time
           ↓
8. Browser displays message with typing effect
           ↓
9. Repeat for each message

================================================================================
                        TROUBLESHOOTING DURING DEPLOYMENT
================================================================================

If build fails:
└─ Check build logs in Vercel
└─ Verify all files were created
└─ Ensure TypeScript is valid
└─ Run `npm install` locally to test

If app loads but chat doesn't work:
└─ Check browser console (F12 → Console tab)
└─ Check Vercel function logs
└─ Verify OPENAI_API_KEY is set
└─ Look for 403/401 errors

If you see API errors:
└─ 500: Backend error (check logs)
└─ 403: Missing/invalid API key (add to env vars)
└─ 429: Rate limited (wait or upgrade OpenAI plan)
