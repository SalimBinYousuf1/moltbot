STEP 3: ADD API KEY TO VERCEL
================================================================================

Your app won't work yet because it needs an OpenAI API key.

OPTION A: From v0 (Recommended)
────────────────────────────────
1. In v0 sidebar, click "Settings" ⚙️
2. Look for "Vars" or "Environment Variables"
3. Click "Add Variable"
4. Name: OPENAI_API_KEY
5. Value: sk-your-actual-key (get from https://platform.openai.com/api-keys)
6. Save and redeploy


OPTION B: From Vercel Dashboard
────────────────────────────────
1. Go to https://vercel.com/dashboard
2. Click your deployed project
3. Click "Settings" tab
4. Click "Environment Variables"
5. Click "Add New"
6. Name: OPENAI_API_KEY
7. Value: sk-your-actual-key
8. Click "Add"
9. Click "Redeploy" or wait for auto-redeploy

TROUBLESHOOTING:

Error: "OPENAI_API_KEY is not set"
→ Go to Vercel Settings → Environment Variables
→ Add OPENAI_API_KEY with your actual key
→ Click "Redeploy"

Error: "Failed to fetch /api/chat"
→ Check browser console (F12 → Console)
→ Check Vercel logs (Vercel dashboard → Functions)
→ Verify API key is valid

App is blank/not loading
→ Hard refresh: Ctrl+F5 (Windows) or Cmd+Shift+R (Mac)
→ Check Vercel build logs for errors
→ Check browser console for JavaScript errors
