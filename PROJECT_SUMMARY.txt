================================================================================
                         HOW TO RUN IT
================================================================================

1. Install dependencies:
   npm install

2. Set environment variables:
   export OPENAI_API_KEY="sk-..."
   export ANTHROPIC_API_KEY="sk-ant-..."  (optional)
   export BRAVE_API_KEY="..."             (optional)

3. Start development server:
   npm run dev

4. Open browser:
   http://localhost:3000

5. Start chatting - all tools are 100% functional!

================================================================================
                        ARCHITECTURE
================================================================================

Browser (Client)
    ↓
    useChat hook (React)
    ↓
POST /api/chat (Next.js Route)
    ↓
ToolLoopAgent (AI SDK)
    ├─ web_search → Real HTTP call
    ├─ fetch_content → Real URL fetch
    ├─ system_info → Real Node.js APIs
    ├─ calculator → Real math eval
    ├─ canvas → Real HTML generation
    └─ session → Real state storage
    ↓
Server-Sent Events (Streaming)
    ↓
Browser displays response in real-time
